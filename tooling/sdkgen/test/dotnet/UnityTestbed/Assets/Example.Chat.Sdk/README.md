# Example Chat Core SDK

A chat network

This package contains the `core` network of the `chat` OpenWS contract (version 1.0.0), generated by `openws-sdkgen`. Each network ships as its own package so it can be versioned and evolved independently. Do not edit the generated files by hand — they are overwritten on the next generation.

## Installation

Install `com.example.chat.sdk` with the Unity Package Manager, e.g. as a local or embedded package, or from your registry via `Packages/manifest.json`:

```json
{
    "dependencies": {
        "com.example.chat.sdk": "1.0.0"
    }
}
```

The `com.unity.nuget.newtonsoft-json` dependency is resolved automatically.

## Consuming the generated library

The package ships two assemblies: `Example.Chat.Core.Sdk` (the generated code) and `Example.Chat.Core.Sdk.User` (an `.asmref` folder whose `partial` handler stubs compile into the SDK assembly).

1. Reference `Example.Chat.Core.Sdk` from your own `.asmdef`, or place your code inside `Runtime/Example.Chat.Core.Sdk.User`.
2. Import the generated namespaces, create the network, wrap it in a `Runtime`, and connect. See the example below.
3. Handle incoming messages by subscribing to the generated `On<Message>` events, or by implementing the `partial Handle<Message>` stubs in `Example.Chat.Core.Sdk.User`.

## Roles

This SDK was generated with the local (host) role `client`; remote roles the host never receives from are not included.

| Role | Host | Description | Endpoints |
| --- | --- | --- | --- |
| `client` | yes | — | — |
| `server` | no | — | `ws://localhost:8082/chat` |

## Usage

```csharp
using Polytric.OpenWs.Core;
using Polytric.OpenWs.Spec.Serialization.Serializer;
using Polytric.OpenWs.Unity;
using UnityEngine;
using Example.Chat.Core;
using Example.Chat.Core.Roles;
using Example.Chat.Core.Models.Server;
using Example.Chat.Core.Models.Client;

class CoreBehaviour : MonoBehaviour, ISessionFactory
{
    async void Start()
    {
        var runtime = new Runtime(new CoreNetwork(), new NewtonSoftSerializer(), this);
        var client = runtime.GetHostRole<Client>();
        var server = await runtime.ConnectAsync<Server>(Server.Endpoints[0]);

        // Send a message to the server role.
        server.CreateRoom(client.Name, new CreateRoomPayload { /* ... */ });

        // React to messages addressed to the client role.
        client.OnJoinedRoom += payload => { /* ... */ };
    }

    public ISession CreateSession() => new NativeWebSocketSession();
}
```
